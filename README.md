For The Quintessential Quintuplets fans, by The Quintessential Quintuplet fan. This project analyzes your body posture and can state whoever you're posing (based from the picture)

This was created via python, Google's MediaPipe framework to track movements, OpenCV for the camera and idk but ye just check the file lil bro

Currently not yet finished (I am still yet to finish Itsuki's and Ichika's for the alpha release



To set it up, you would need to download OpenCV, MediaPipe and Pygame (Pygame will be used for future use)



If on Windows:
Open Git and run the following command:
```bash
git clone https://github.com/pringlecorte/The-Quintessential-Quintuplets-Pose-Tracker
```

Open Windows Powershell/Command Prompt and type this in:

```bash
pip install opencv-python "mediapipe<=0.10.14"
```

Afterwards, you just wanna skedaddle to the folder and open the file

```bash
cd %USERPROFILE%\The-Quintessential-Quintuplets-Pose-Tracker && python "The Quintessential Quintuplets Pose Tracker.py"
```

P.S. Press Q to stop the code
